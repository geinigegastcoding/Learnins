# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

The primary user is the owner, studying for test weeks, learning languages and other facts, and improving programming skills. Sharing the application later is a possibility, not a current requirement.

## Product Purpose

Learnins is a local-first learning environment. It helps the learner work from their current understanding toward a goal, practise, revisit knowledge, and organize study before exams.

## Operating Context

The existing application runs as an Electron desktop app with a local web interface. The learner brings their own model access and may import course materials, including files and exported Teams content. Calendar handoff should work with Google Calendar.

## Capabilities and Constraints

- Preserve the existing measure, plan, teach and practice learning flow and persistent knowledge graph.
- Support provider setup, learning materials, research, programming practice, flashcards and test-week planning.
- Keep personal learning data local. External AI, search and calendar services still receive data when the learner chooses to use them.
- Support free search and real, testable workflows; expose missing integration or configuration honestly.

## Brand Commitments

The product is named Learnins. Its desktop interface should approach T3 Code in clarity, usability and visual quality.

## Evidence on Hand

The fork's README and `LEARNINS_ROADMAP.md` describe the inherited product and the requested work. The planning conversation is the source of the learner's goals.

## Product Principles

- Help the learner start and continue a real task quickly.
- Make model connections and local data ownership understandable.
- Keep learning workflows grounded in actual materials and observable results.
- Preserve useful knowledge across sessions.
